Code Zero is a TypeScript monorepo. Every tool below was chosen deliberately; the toolchain rules in [AGENTS.md](https://github.com/wolfstar-project/code-zero/blob/main/AGENTS.md) are binding for contributors and coding agents alike.

## Runtime and package management

- **[Node.js](https://nodejs.org) 24.2+** — the minimum runtime for every package and generated bundle.
- **[aube](https://aube.jdx.dev)** — the package manager, pinned through `packageManager` in `package.json`. aube reads and writes the existing `pnpm-lock.yaml` and `pnpm-workspace.yaml` in place, so the lockfile stays in pnpm's v9 format for anyone who still runs pnpm. Do not use npm, Yarn, or Bun in this repository, and do not add a second lockfile.
- **[mise](https://mise.jdx.dev)** — `mise.toml` pins both Node.js and aube, so one `mise install` sets up the whole toolchain.

## Build and orchestration

- **[Turborepo](https://turborepo.dev)** — schedules workspace tasks in dependency order and caches build outputs. All orchestration goes through the root scripts; packages do not duplicate it.
- **[tsdown](https://tsdown.dev)** — builds publishable packages as ESM and CommonJS with matching declarations and source maps, through the shared [`scripts/tsdown.config.ts`](https://github.com/wolfstar-project/code-zero/blob/main/scripts/tsdown.config.ts). The Nuxt dashboard uses the Nuxt build pipeline instead.
- **[typescript-native-bridge](https://github.com/johnsoncodehk/typescript-native-bridge)** — overrides `typescript` repo-wide in `pnpm-workspace.yaml`, so `tsc` keeps the classic package surface while the checker runs on tsgo in-process. The pin is exact because the fork only publishes prerelease versions.

## Quality gates

- **[Oxlint](https://oxc.rs) + [Oxfmt](https://oxc.rs)** — type-aware linting and repository-wide formatting, extended with [`@e18e/eslint-plugin`](https://github.com/e18e/eslint-plugin) for modernization and performance rules. ESLint and Prettier are deliberately absent.
- **[Knip](https://knip.dev)** — detects unused files, exports, and dependencies across the workspace as part of `lint:ci`.
- **[Vitest](https://vitest.dev)** — deterministic unit tests beside the source as `*.test.ts`; [Playwright](https://playwright.dev) drives the dashboard's end-to-end suite.
- **[`@arethetypeswrong/cli`](https://github.com/arethetypeswrong/arethetypeswrong.github.io) + [Publint](https://publint.dev)** — validate every package build.

## Application stack

- **[Nuxt](https://nuxt.com) 4** — the dashboard, the single deployable app: UI, control plane, and authentication from one origin, served by Nuxt's own Nitro server.
- **[UnoCSS](https://unocss.dev)** (preset-wind4) with **[@nuxt/icon](https://github.com/nuxt/icon)** (Lucide, bundled locally) — styling and icons.
- **[oRPC](https://orpc.unnoq.com)** — one typed router served over both a typed RPC transport (`/rpc/**`) and OpenAPI/REST (`/api/v1/**`).
- **[Better Auth](https://better-auth.com)** via [`@onmax/nuxt-better-auth`](https://github.com/onmax/nuxt-better-auth) — authentication mounted in-process at `/api/auth/**`.
- **[Drizzle](https://orm.drizzle.team) + Postgres** — the session store, the only database in the repository, owned by `packages/database` with reviewable checked-in SQL migrations.
- **[Maizzle](https://maizzle.com)** — transactional email templates in `packages/mail`.
- **[@nuxtjs/i18n](https://i18n.nuxtjs.org)** + **[Lunaria](https://lunaria.dev)** — English and Italian dictionaries with translation-staleness reporting.
- **[Vercel AI SDK](https://sdk.vercel.ai)** — the model-provider integrations behind one `ModelProvider` contract in `packages/models`.

## Agent tooling

- **[skilld](https://github.com/skilld-labs/skilld)** — manages the Agent Skills in `.skills/` that expose task-specific guidance to coding agents. See [Agent Skills](/guide/codebase/agent-skills).
- **[`@redstardev/unplugin-version-injector`](https://www.npmjs.com/package/@redstardev/unplugin-version-injector)** — injects the version marker the CLI displays in its header.
